# MobileStack — El ciclo de vida del desarrollo móvil

Blog académico para el curso **Análisis de Sistemas II**, tarea "Ciclo de Vida del Desarrollo Móvil".

## Archivos

- `index.html` — el artículo completo.
- `style.css` — estilos (tema oscuro, tipografía Sora + IBM Plex).

## Cómo publicarlo en GitHub Pages

1. Crea un repositorio nuevo en GitHub (puede ser público, ej. `ciclo-vida-desarrollo-movil`).
2. Sube `index.html` y `style.css` a la raíz del repositorio (arrastrarlos en la página de GitHub funciona: botón **Add file → Upload files**).
3. Ve a **Settings → Pages** dentro del repositorio.
4. En "Branch", selecciona `main` (o `master`) y la carpeta `/ (root)`, luego **Save**.
5. Espera 1–2 minutos. GitHub te dará una URL como:
   `https://tu-usuario.github.io/ciclo-vida-desarrollo-movil/`
6. **Antes de entregar la tarea**, abre esa URL en una ventana de incógnito para confirmar que cualquier persona puede verla sin iniciar sesión.

## Editar contenido

- El nombre del catedrático está vacío a propósito (`<dd>&nbsp;</dd>` dentro de la sección "Catedrático" en `index.html`) — complétalo con el nombre real antes de publicar.
- Todo el texto está directamente en `index.html`; puedes editarlo con cualquier editor de texto.
